- **Windows Fundamentals 2**
	- In this room I learned about the System Configuration utility. The room went over a few of the tools available in the Utility such as:
		- Change UAC settings
			- This was covered more in Windows Fundamentals 1, which I regrettably forgot to note when I progressed through it.
		- Computer Management
			- This tool was really cool, its like an all in one dashboard of utilites, we explored Task scheduler. [[Event_Viewer]](which got its own note file, it seems like an important diagnostic tool!), windows logs was very briefly touched on, so was shared folders. There were a couple others that barely got a glace such as sessions, open files local users and groups, performance, device manager, storage, and lastly services and applications. It was really just a nice refresher course for A+ material in a lab envvironment.
		- System Information(msinfo32)
			- This was another utility that was grazed over, It seems like a super useful collection of system data which seems very useful in diagnostic situations or referencing hardware, though there may be better resources for quick referencing in the system settings.
		- Resource Monitor
			- This is a utility that displays resource utilization all in one place for many hardware devices such as CPU, Disk, Network, and Memory. 
		- Command Prompt
			- windows CLI utility, we ran a few commands:
				- `hostname` — Prints name of host machine
				- `whoami` — Prints logged-in user  
				- `ipconfig` — Displays network address settings  
				- `/?` — Help flag  
				- `ipconfig /?` — Shows the help manual for ipconfig  
				- `cls` — Clears the terminal  
				- `netstat` — Displays protocol stats and current TCP/IP network connections  
				- `net` — Used to manage network resources  
				- `net help` — Shows the net manual page  
				- `net user` — Creates and modifies user accounts on computers  
				- `net help user` — Displays manual for net user sub-command  
		- Registry Editor
			- According to Microsoft the Windows Registry is a central hierarchical database used to store necessary information to configure the system for one or more users applications and hardware devices. This information is continually referenced during operation.
			- You can break things really good here, tinkering only advised on VM's
