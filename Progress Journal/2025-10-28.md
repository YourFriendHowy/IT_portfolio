	- Learned about the DNS hierarchy
		- The forest is the top level, or root container. It contains one or more domains. All domains in the same forest share a global catalog, trust relationships and rules for objects and attributes.
		- Each domain in a tree in the forest. These contain resources such as users, groups and computers. Each domain has its own policies, authentication, and namespace. Domains can inherit from the forest but maintain their own control for management and replication.
		- Domain controllers are the servers that run active directory domain services. t6hey store the AD database, authenticate logins(via kerberos), replicates data to other DCs in the same domain. DCs are used in tandem on a single domain for redundancy and load balancing.
