- **Windows Fundamentals 3**
	- In this room we covered security features within the windows operating system
		- Windows Updates
			- Is a service provided by Microsoft to supply security updates, feature enhancements, and patches for the operating system and other installed Microsoft products, such as windows defender.
			- Updates are typically released on the second Tuesday of each month(I did not know this, that's helpful information) Some updates may be deemed critical and released sooner.
			- Microsoft added auto-updates in windows 10 due to users avoiding them. Usually because of the required restart.
		- Windows Security
			- This section offers a general overview of the windows security tab, not much depth and beyond what you see is what you get
		- Virus and Threat Protection
			- A continuation of Windows security
			- This window shows Scan options and threat/scan history
				- **Quick Scan** - Checks folders in system that threats can commonly be found in
				- **Full scan** - Checks all files and running programs, Scan can take over an hour to run.
				- **Custom Scan** - User chooses which files and locations to scan
				- **Last scan** - Windows defender auto scans the computer for threats and viruses, this shows the last date it was ran.
				- **Quarantined Threats** Isolated threats preventing them from running on the device, will be periodically removed.
				- **Allowed Threats** - Allowed threats are items that have been identified as threats but the user has allowed them to run anyways.
			- The remainder of this task goes on to discuss other items in virus and threat protection, all of which is quite straight forward and self explanatory. I know detailed notes are good, but this topic is well understood.
		- Firewall & network protection
			- Per Microsoft, "_Traffic flows into and out of devices via what we call ports. A firewall is what controls what is - and more importantly isn't - allowed to pass through those ports. You can think of it like a security guard standing at the door, checking the ID of everything that tries to enter or exit_".
			- Firewall Profiles
				- **Domain** - The domain profile applies to networks where the host system can authenticate to a domain controller._
				- **Private** - The private profile is a user-assigned profile and is used to designate private or home networks.
				- **Public** - The default profile is the public profile, used to designate public networks such as Wi-Fi hotspots at coffee shops, airports, and other locations.
