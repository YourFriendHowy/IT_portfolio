**VLAN ID/tags** - These are used to tell the switch which VLAN network the data is meant to be on.  VLAN10, VLAN20 etc

**Untagged** - the default VLAN a device without a specific VLAN id will be assigned when plugged into a network port.

**Tagged** - additional VLANs on a network port for devices that are 'aware' of which VLAN they are supposed to be assigned to

**Trunk Port** - a network port on a switch or router that is configured to carry traffic for multiple CLANs
